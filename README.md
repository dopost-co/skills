# dopost-co/skills

Agent skills for AI coding assistants (Cursor, GitHub Copilot, Claude Code, and more).

## Install

```sh
npx skills add dopost-co/skills
```

## Available Skills

| Skill | Description |
|-------|-------------|
| [seo-audit](./seo-audit/SKILL.md) | Full technical + on-page SEO audit |

## Usage with specific agents

```sh
# Cursor
npx skills add dopost-co/skills -a cursor

# GitHub Copilot
npx skills add dopost-co/skills -a github-copilot

# Claude Code
npx skills add dopost-co/skills -a claude-code
```
